# Invitación Virtual

Proyecto base para una invitación virtual desplegable en Vercel.

## Instrucciones

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Ejecuta el modo de desarrollo:
   ```bash
   npm run dev
   ```
3. Construye para producción:
   ```bash
   npm run build
   ```
4. Para Vercel, conecta esta carpeta y usa el comando de build `npm run build`.

## Estructura

- `src/App.tsx`: plantilla principal de la invitación.
- `src/index.css`: estilos globales con Tailwind.
- `public/` opcional para imágenes y assets.
